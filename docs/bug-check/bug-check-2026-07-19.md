## 风险维度审查结论（18 项）
| 风险维度 | 结论 |
|---|---|
| SQL 注入（routes/services） | 全部使用参数化查询（`$1, $2...`），动态 SQL 使用白名单字段（`UPDATABLE_SERVICE_FIELDS`、`ALLOWED_FIELDS` 等） |
| 未授权访问 | 所有写操作路由接入 `authenticate` + `requireRole('admin')`，公开路由仅限统计/健康检查 |
| 参数校验缺失 | 所有路由使用 `express-validator` + `validate` 中间件 |
| 异常处理缺失 | 所有 async 路由通过 `asyncHandler` 包装，全局 `errorHandler` 兜底 |
| 事务边界错误 | 积分/状态变更全部在 `transaction + FOR UPDATE` 内，`lockUsersForUpdate` 按 id 升序避免死锁 |
| 资源泄漏 | `pool.connect()` 均在 `finally` 中 `release()`（`metrics.service.ts`、`health.ts`） |
| 认证绕过 | `authenticate` 中间件校验 JWT + DB 状态 + token 黑名单 |
| 限流绕过 | Redis 限流 + 内存降级，关键端点（auth/createPost/order）独立限流器 |
| `sql.ts` 注入风险 | `prefixColumns` 仅对硬编码列名加前缀，无用户输入 |
| `crypto.ts` 加密正确性 | AES-256-GCM + `scryptSync` 密钥派生 + 16 字节 IV + authTag 验证 |
| `fs/http` 未关闭/超时 | `notification-channels.ts` 中 SMTP/短信网关调用通过 `withTimeout` 包装（10s 超时） |
| `JSON.parse` 未 try/catch | 前端 `jwt.ts`、`websocket.ts`、`ab-test.ts` 均有 try/catch |
| `crypto.randomUUID()` 误用 | 全局搜索仅 `__tests__/tokenBlacklist.test.ts` 使用，生产代码未误用 |
| `dangerouslySetInnerHTML` 误用 | 全局搜索**无任何使用**，无 XSS 风险 |
| setState 泄漏 | 12 处已修复（Emergency/AIRecommend/SharedKitchen-Detail/SkillExchange-Detail/TimeBank-ServiceDetail/TimeBank-index/SkillExchange-index/Toast/ResourceMap/Layout/Home/Chat），本轮审查确认无新增遗漏 |
| XSS 防护 | `format.ts` 提供 `escapeHtml`，后端 `sanitizeXss + sanitizeObject` 兜底 |
| 表单未校验提交 | `SharedKitchen/Create.tsx`、`SkillExchange/Create.tsx`、`TimeBank/CreateService.tsx`、`Profile/Verify.tsx`、`Login.tsx`、`Register.tsx` 均使用 `useFormValidation` + `validateAll` |
