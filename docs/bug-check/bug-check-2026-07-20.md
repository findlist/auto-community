## 修复模式说明

本次修复统一采用项目既有的 `mountedRef` 防御模式（参考 `2cda9ca`、`c96e603`、`57c5cd0` 等近期提交）：

1. 新增 `const mountedRef = useRef(true);`
2. 在 `useEffect` 内开头置 `mountedRef.current = true`（防止 React Strict Mode 双调用遗留 false 值）
3. 在 `useEffect` cleanup 中置 `mountedRef.current = false`
4. 所有 await 之后、setState 之前加 `if (!mountedRef.current) return;`
5. `finally` 块内使用 `if (mountedRef.current) setXxx(...)` 守卫

该模式与 HomepageImage、ABTestResults、SystemConfig、AddressBook、MyOrders 等已修复页面保持一致，符合项目工程规范。
