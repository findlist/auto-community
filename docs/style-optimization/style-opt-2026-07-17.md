## 具体修改内容

### 1. 首页终极 CTA 氛围层次增强

**文件**：`src/pages/Home/index.tsx`

**改动**：
- 将 CTA 区背景由纯色 `bg-neutral-900` 升级为对角渐变 `bg-gradient-to-br from-neutral-900 via-neutral-900 to-emerald-950/40`，左上至右下引入极淡的邻里绿调，与品牌主色呼应。
- 在原有右侧邻里绿光晕基础上，新增左下角互补微光（`bg-emerald-400/5`），构建非对称氛围深度，避免单侧光晕的视觉偏沉。

**优化前**：
```jsx
<section className="... bg-neutral-900 text-white relative overflow-hidden">
  <div className="absolute top-1/2 -right-32 w-96 h-96 rounded-full bg-emerald-500/10 blur-3xl ..." />
```

**优化后**：
```jsx
<section className="... bg-gradient-to-br from-neutral-900 via-neutral-900 to-emerald-950/40 text-white relative overflow-hidden">
  <div className="absolute top-1/2 -right-32 w-96 h-96 rounded-full bg-emerald-500/10 blur-3xl ..." />
  <div className="absolute -bottom-24 -left-24 w-80 h-80 rounded-full bg-emerald-400/5 blur-3xl ..." />
```

**对比说明**：原 CTA 区为纯黑底 + 单侧光晕，氛围偏平。优化后通过极淡渐变与双侧光晕，在保持克制的前提下增加纵深感，让“最好的邻居，从来都是第一次见面”这句文案更具沉浸氛围。

### 2. 三大模块“发布”按钮模块色身份强化

**文件**：
- `src/pages/TimeBank/index.tsx`
- `src/pages/SharedKitchen/index.tsx`
- `src/pages/SkillExchange/index.tsx`

**改动**：
三个模块入口页的“发布”按钮原本完全相同（`bg-neutral-900 hover:bg-neutral-800`），缺少模块身份反馈。为每个按钮的悬停态添加对应模块色的柔光阴影：

| 模块 | 模块色 | 新增 hover 阴影 |
|------|--------|-----------------|
| 时间银行 | 紫 `#8b5cf6` | `hover:shadow-[0_8px_24px_-8px_rgba(139,92,246,0.5)]` |
| 共享厨房 | 橙 `#f97316` | `hover:shadow-[0_8px_24px_-8px_rgba(249,115,22,0.5)]` |
| 技能交换 | 蓝 `#3b82f6` | `hover:shadow-[0_8px_24px_-8px_rgba(59,130,246,0.5)]` |

**优化前**：
```jsx
className="... bg-neutral-900 text-white rounded-full ... hover:bg-neutral-800 active:scale-[0.97] transition-all duration-200"
```

**优化后**（以时间银行为例）：
```jsx
className="... bg-neutral-900 text-white rounded-full ... hover:bg-neutral-800 hover:shadow-[0_8px_24px_-8px_rgba(139,92,246,0.5)] active:scale-[0.97] transition-all duration-200"
```

**对比说明**：原三模块按钮视觉完全一致，用户在多个模块间切换时缺乏色彩锚点。优化后悬停时按钮周围浮现对应模块色光晕，与页面标题色点、Tab 下划线、列表悬停态形成完整的模块色链路，强化“我在哪个模块”的感知。光晕透明度控制在 0.5，保持按钮的克制气质。

### 3. Auth 页面提交按钮触觉反馈增强

**文件**：
- `src/pages/Auth/Login.tsx`
- `src/pages/Auth/Register.tsx`
- `src/pages/Auth/ForgotPassword.tsx`
- `src/pages/Auth/ResetPassword.tsx`

**改动**：
4 个 Auth 页面的主提交按钮（白色按钮）原本仅有 `active:scale-[0.98]` 按压缩放，缺少悬停反馈。新增悬停微抬升与阴影增强，并补充 disabled 状态下的回退（避免禁用按钮也抬升）：

**优化前**：
```jsx
className="... hover:bg-neutral-100 active:scale-[0.98] disabled:opacity-50 disabled:cursor-not-allowed transition-all duration-200 ... shadow-lg shadow-black/10"
```

**优化后**：
```jsx
className="... hover:bg-neutral-100 hover:-translate-y-0.5 hover:shadow-xl hover:shadow-black/25 active:scale-[0.98] disabled:opacity-50 disabled:cursor-not-allowed disabled:hover:translate-y-0 disabled:hover:shadow-lg transition-all duration-200 ... shadow-lg shadow-black/10"
```

**对比说明**：
- 悬停时按钮上浮 2px（`-translate-y-0.5`）+ 阴影由 `shadow-lg` 增至 `shadow-xl`，形成“可按下”的触觉预期。
- 按下时仍保留 `active:scale-[0.98]` 缩放，形成“悬浮 → 按下”的完整反馈链。
- 新增 `disabled:hover:*` 回退类，确保 loading 中按钮不会因 hover 抬升造成视觉抖动。
- 4 个 Auth 页面保持一致，维持表单组件的统一语言。

### 4. 管理后台 Dashboard 统计卡片色条锚点

**文件**：`src/pages/Admin/Dashboard.tsx`

**改动**：
为 7 张统计卡片的 `cardConfig` 新增 `bar` 字段（模块色 hex），并在卡片顶部渲染 2px 色条，配合 `overflow-hidden` 让色条贴合圆角。

**配置扩展**：
```ts
const cardConfig: Array<{ ...; bar: string }> = [
  { key: "totalUsers", ..., bar: "#3b82f6" },       // 蓝
  { key: "todayNewUsers", ..., bar: "#10b981" },    // 邻里绿
  { key: "skillOrders", ..., bar: "#8b5cf6" },      // 紫
  { key: "kitchenOrders", ..., bar: "#f97316" },    // 橙
  { key: "timeBankOrders", ..., bar: "#06b6d4" },   // 青
  { key: "emergencyRequests", ..., bar: "#ef4444" },// 红
  { key: "pendingReports", ..., bar: "#eab308" },   // 黄
];
```

**卡片渲染**：
```jsx
<div className="... relative overflow-hidden">
  {/* 顶部色条：模块色锚点，提升多卡扫读效率 */}
  <span className="absolute top-0 left-0 right-0 h-0.5" style={{ backgroundColor: bar }} />
  <div className={`w-10 h-10 rounded-lg ... ${bg}`}>
    <Icon className={`w-5 h-5 ${color}`} />
  </div>
  ...
</div>
```

**对比说明**：原 7 张卡片仅靠图标背景色区分，多卡扫读时色彩锚点偏弱（图标背景为浅色 50 阶）。优化后顶部 2px 色条使用 500 阶饱和色，扫读时一眼可定位“红=应急、橙=厨房、紫=技能”，与图标背景形成“强锚点 + 弱背景”的双层色彩层级。色条高度克制在 2px，不破坏卡片整体克制气质。
