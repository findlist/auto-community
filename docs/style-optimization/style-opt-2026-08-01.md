# UI 优化记录 2026-08-01 (community)

## 修改文件

### client/src/pages/Emergency/index.tsx — RequestCard 键盘可访问性

**问题**：L148 RequestCard 根元素是带 `onClick` 和 `cursor-pointer` 的 `<div>`（点击导航到 `/emergency/${request.id}`），但缺少 `role="button"`、`tabIndex`、`onKeyDown`，键盘用户无法通过 Tab 聚焦、无法用 Enter/Space 触发导航，屏幕阅读器不会将其识别为可交互元素。同文件 ResponseItem 内的可交互元素均使用 `<button>`（如 L674-681 "确认到达"按钮），StarRating 使用 `<button type="button">`，唯独 RequestCard 作为"整行可点击导航"的列表项既未改用 `<button>` 也未补充 ARIA 属性，是项目内的孤立违规模式。

**修改**：
- L148-153：新增 `role="button" tabIndex={0} onKeyDown`，onKeyDown 复用 onClick 同一 navigate 调用（Enter/Space 触发，与 auto-game HomeTopSection 内联模式一致）

**评分**：Score=44, C=5, R=1（通过门槛 Score>=22, C>=4, R<=1）
