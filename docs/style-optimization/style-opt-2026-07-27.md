## 三、具体修改内容

### 1. 玻璃态表单自动填充样式修复

**涉及文件**：
- `src/index.css`
- `src/pages/Auth/Login.tsx`
- `src/pages/Auth/Register.tsx`
- `src/pages/Auth/ForgotPassword.tsx`
- `src/pages/Auth/ResetPassword.tsx`

**问题背景**：认证页表单使用玻璃态（`bg-white/10 backdrop-blur-xl`），但 Chrome 自动填充会注入浅黄色背景与黑色文字，破坏玻璃态视觉一致性。

**修改内容**：

在 `src/index.css` 中新增 `.glass-form` 工具类，统一覆盖自动填充样式：

```css
/* 玻璃态表单输入框自动填充覆盖 */
.glass-form input:autofill,
.glass-form input:-webkit-autofill {
  -webkit-text-fill-color: #ffffff;
  -webkit-box-shadow: 0 0 0 1000px rgba(255, 255, 255, 0.05) inset;
  caret-color: #ffffff;
  transition: background-color 9999s ease-out 0s;
}
```

在四个认证页表单元素上挂载 `glass-form` 类：

```tsx
<form
  onSubmit={handleSubmit}
  className="glass-form bg-white/10 backdrop-blur-xl border border-white/20 rounded-2xl p-6 lg:p-8 space-y-5 animate-fade-in-up shadow-2xl transition-shadow duration-300 hover:shadow-[0_25px_600px_-15px_rgba(0,0,0,0.5)]"
  style={{ animationDelay: "120ms" }}
>
```

### 2. 管理后台状态徽章配色统一

**涉及文件**：
- `src/pages/Admin/UserManagement.tsx`
- `src/pages/Admin/ContentReview.tsx`
- `src/pages/Admin/AuditLog.tsx`
- `src/pages/Admin/ReportManagement.tsx`
- `src/pages/Admin/VerificationReview.tsx`

**问题背景**：管理后台状态徽章混用 `green-*` 与 `emerald-*` 两套绿色色阶，破坏品牌一致性。

**修改内容**：统一将 `bg-green-100 text-green-700` 替换为 `bg-emerald-100 text-emerald-700`，与项目主色板对齐。

```tsx
<span
  className={`px-2 py-0.5 rounded text-xs ${
    u.status === "banned"
      ? "bg-red-100 text-red-700"
      : "bg-emerald-100 text-emerald-700"
  }`}
>
  {u.status === "banned" ? "已封禁" : "正常"}
</span>
```

### 3. 列表项错落入场动画

**涉及文件**：
- `src/pages/TimeBank/ServiceCard.tsx`
- `src/pages/SharedKitchen/index.tsx`
- `src/pages/SkillExchange/index.tsx`

**问题背景**：列表项首次渲染时同时出现，缺乏入场节奏，视觉冲击力弱。

**修改内容**：为列表项根元素挂载 `stagger-item` 类，复用全局定义的错落入场动画（30ms 递进延迟，最多 270ms）。

```tsx
<div
  onClick={onClick}
  className="stagger-item group flex items-start gap-4 lg:gap-6 border-b border-neutral-200 py-5 lg:py-6 cursor-pointer transition-colors duration-200 hover:bg-neutral-50/60 -mx-4 px-4 lg:-mx-6 lg:px-6"
>
```

### 4. 技能交换下拉箭头自定义

**涉及文件**：`src/pages/SkillExchange/index.tsx`

**问题背景**：分类筛选 `<select>` 使用浏览器默认箭头，与搜索框 `Search` 图标的视觉语言不一致。

**修改内容**：

1. 引入 `ChevronDown` 图标
2. 使用 `appearance-none` 隐藏原生箭头
3. 通过 `relative/absolute` 容器叠加自定义箭头
4. `pointer-events-none` 避免图标拦截点击

```tsx
<div className="relative">
  <select
    value={selectedCategory}
    onChange={e => setSelectedCategory(e.target.value)}
    className="w-full pl-4 pr-10 py-2.5 bg-neutral-100 border border-transparent rounded-lg text-sm text-neutral-700 focus:outline-none focus:bg-white focus:border-blue-400 focus:ring-2 focus:ring-blue-500/15 transition-all cursor-pointer appearance-none"
  >
    {categories.map(cat => (
      <option key={cat} value={cat}>{cat}</option>
    ))}
  </select>
  <ChevronDown className="pointer-events-none absolute right-3.5 top-1/2 -translate-y-1/2 w-4 h-4 text-neutral-400" />
</div>
```

### 5. 首页页脚滚动揭示动画

**涉及文件**：`src/pages/Home/index.tsx`

**问题背景**：首页首屏与功能模块均有入场/滚动揭示动画，但页脚直接静态展示，动画节奏在页面底部断裂。

**修改内容**：通过 `useScrollReveal` Hook 为页脚注册滚动揭示，与全页动画流保持一致。

```tsx
const { ref: footerRef, visible: footerVisible } = useScrollReveal<HTMLElement>();

<footer
  ref={footerRef}
  className="py-10 px-6 text-center bg-neutral-900 text-neutral-500 text-xs border-t border-white/5 transition-all duration-700"
  style={{
    opacity: footerVisible ? 1 : 0,
    transform: footerVisible ? "translateY(0)" : "translateY(12px)",
  }}
>
```

## 四、优化前后对比说明

### 1. 视觉层次

| 维度 | 优化前 | 优化后 |
| --- | --- | --- |
| 列表入场 | 列表项同时渲染，视觉冲击扁平 | 30ms 递进错落入场，引导视线下移 |
| 页面动画节奏 | 首屏动画充分，页脚断裂 | 首屏到页脚动画流连贯 |
| 表单自动填充 | Chrome 黄色背景破坏玻璃态 | 自动填充背景与玻璃态融合 |
| 后台徽章 | green/emerald 混用 | 统一 emerald 色阶，品牌一致 |

### 2. 交互体验

| 维度 | 优化前 | 优化后 |
| --- | --- | --- |
| 下拉箭头 | 浏览器默认箭头风格不一 | ChevronDown 与搜索图标语言统一 |
| 卡片悬停 | 已有 `hover:bg-neutral-50/60` | 配合 `translate-x-1` 标题位移强化反馈 |
| 滚动揭示 | 仅首屏与中部模块有 | 全页（含页脚）动画流闭环 |

### 3. 设计质量

| 维度 | 优化前 | 优化后 |
| --- | --- | --- |
| 配色一致性 | 后台存在两套绿色色阶 | 全局统一为 emerald 色阶 |
| 图标语言 | 搜索框自定义图标 + 原生 select 箭头 | 全部使用 lucide 图标族 |
| 动画一致性 | 列表页入场节奏不统一 | TimeBank/SharedKitchen/SkillExchange 三处列表页统一为 stagger-item |
| 品牌色板 | green 与 emerald 共存 | emerald 作为唯一绿色品牌色 |

### 4. 响应式布局

- **Tab 横向滚动**：`SkillExchange/index.tsx` 中 Tab 容器使用 `overflow-x-auto` + `whitespace-nowrap`，移动端窄屏 Tab 文字不换行、可横向滚动，避免下划线动效错位。
- **列表项标题/价格行**：移动端纵向堆叠（`flex-col sm:flex-row`），避免 `whitespace-nowrap` 的积分价格挤压标题。
