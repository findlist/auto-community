## 审查基线评估

延续 07-18 的优化基线，本次审查发现 Create 表单页三件套与订单页存在以下模块色身份链路断裂问题：

- ✅ 列表页（TimeBank/SkillExchange/SharedKitchen 的 `index.tsx`）已在 07-16/07-17 完成模块色 Tab 下划线统一（紫/蓝/橙）
- ⚠ 三个模块的 Create 表单页统一使用 `bg-emerald-600`（主色绿）作为类型切换按钮与提交按钮配色，与各模块列表页 Tab 下划线色完全不一致，模块身份在「发布入口」节点断裂
- ⚠ 表单输入框焦点环使用 `focus:ring-emerald-500`，与项目其他页面（如 ServiceDetail 编辑弹窗、登录页）的 `focus:ring-{moduleColor}-500/15 focus:border-{moduleColor}-400` 规范不一致
- ⚠ 大量 `text-gray-*`/`bg-gray-*`/`border-gray-*` 未迁移到 `neutral-*` 设计令牌
- ⚠ ServiceDetail 内的 EditServiceModal 与 DetailSkeleton 仍残留 emerald 与 gray，与主体优化脱节
- ⚠ MyOrders 的状态徽章 `in_progress` 使用 emerald 与 `completed` 使用 green 形成视觉混淆；操作按钮组（接受/开始/完成）色彩混杂（emerald/blue/green），缺少模块身份

基于以上发现，本次仅做模块色身份贯通与令牌对齐，不改动任何业务逻辑、状态管理、API 调用。

## 具体修改内容

### 1. 时间银行 CreateService —— 模块紫贯通

**文件**：`src/pages/TimeBank/CreateService.tsx`

**改动**：
将类型切换按钮、表单输入框焦点环、分类按钮、提交按钮的 emerald 主色全部改为时间银行模块紫（violet-600），同时将所有 `gray-*` 迁移到 `neutral-*` 设计令牌。

**优化前**：
```tsx
// 类型切换按钮
className={`flex-1 py-2.5 rounded-lg text-sm font-medium transition-colors ${
  form.type === val
    ? "bg-emerald-600 text-white"
    : "bg-gray-100 text-gray-600"
}`}

// 表单输入框
className={`w-full px-3 py-2.5 bg-gray-50 border rounded-lg text-sm focus:outline-none focus:ring-2 focus:ring-emerald-500 ${
  getFieldError("category") ? "border-red-500" : "border-gray-200"
}`}

// 提交按钮
className="w-full mt-6 py-3 bg-emerald-600 text-white rounded-lg font-medium hover:bg-emerald-700 transition-colors"
```

**优化后**：
```tsx
// 类型切换按钮：使用时间银行模块紫，与列表页 Tab 下划线 bg-violet-600 一致
className={`flex-1 py-2.5 rounded-lg text-sm font-medium transition-colors ${
  form.type === val
    ? "bg-violet-600 text-white"
    : "bg-neutral-100 text-neutral-600 hover:bg-neutral-200"
}`}

// 表单输入框：焦点环升级为 violet 15% 透明度光晕 + 400 阶边框
className={`w-full px-3 py-2.5 bg-neutral-50 border rounded-lg text-sm focus:outline-none focus:ring-2 focus:ring-violet-500/15 focus:border-violet-400 transition-all ${
  getFieldError("category") ? "border-red-500" : "border-neutral-200"
}`}

// 提交按钮：与列表页发布按钮配色一致
className="w-full mt-6 py-3 bg-violet-600 text-white rounded-lg font-medium hover:bg-violet-700 transition-colors"
```

**对比说明**：原 CreateService 是「绿色孤岛」，用户从列表页（紫 Tab）→ 详情页（紫徽章）→ CreateService（绿按钮）的链路在最后一步断裂。优化后整条发布链路（列表 → 创建 → 提交）形成完整的紫色身份流，用户的模块认知在每一步都得到强化。

### 3. 时间银行 MyOrders —— 状态徽章与操作按钮规范

**改动**：

- 状态 Tab 激活态：`bg-emerald-600` → `bg-violet-600`，未选中态 gray→neutral
- 评价输入框焦点环：`focus:ring-emerald-500` → `focus:ring-violet-500/15 focus:border-violet-400 transition-all`

- loading spinner：`text-emerald-500` → `text-violet-500`
- 所有文字 gray-* → neutral-*

**优化前**：
```tsx

// 操作按钮组：接受=emerald，开始=blue，完成=emerald，色彩混杂

<button className="... bg-blue-600 ... hover:bg-blue-700">开始服务</button>
<button className="... bg-emerald-600 ... hover:bg-emerald-700">完成服务</button>
<button className="... bg-gray-100 text-gray-600 ... hover:bg-gray-200">取消</button>
```

**优化后**：
