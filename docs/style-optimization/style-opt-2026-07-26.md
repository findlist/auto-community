### 本次发现的可优化点

- ⚠ **TimeBank Tab 容器下边距与同类列表页不一致**：三个列表页（TimeBank / SharedKitchen / SkillExchange）共享相同的页面结构（标题 + 发布按钮 → Tab 切换 → 筛选/入口 → 列表），但 TimeBank 的 Tab 容器使用 `mb-6`（24px），而 SharedKitchen 和 SkillExchange 均使用 `mb-5`（20px）。同结构页面应保持相同的节奏间距，4px 的差异在并排对比时能感知到视觉节奏的不一致。
- ⚠ **Layout 移动端底部导航缺少激活态视觉锚点**：桌面端 `DesktopNavLink` 激活时有底部 underline 指示器（`absolute bottom-0 left-3 right-3 h-px` + `scale-x-100`），但移动端 `MobileTabItem` 激活态仅有颜色变化（`text-neutral-900`）+ 图标缩放（`scale-110`），缺少与桌面端对等的线状指示器。移动端底部导航是核心导航入口，激活态视觉锚点的缺失影响一眼可读性。

基于以上发现，本次仅做边距一致性对齐与激活态指示器补全，不改动任何业务逻辑、状态管理、API 调用。

## 具体修改内容

### 1. TimeBank Tab 容器 —— 下边距一致性对齐

**文件**：`src/pages/TimeBank/index.tsx`

**改动**：
将 Tab 容器的 `mb-6`（24px）调整为 `mb-5`（20px），与 SharedKitchen / SkillExchange 列表页的 Tab 容器边距保持一致。补充注释说明对齐理由。

**优化前**：
```tsx
{/* Tab 切换：下划线式，激活态下划线使用时间银行模块紫 */}
{/* overflow-x-auto + whitespace-nowrap：移动端窄屏 Tab 文字不换行、可横向滚动，避免下划线动效错位 */}
<div className="flex items-center gap-6 border-b border-neutral-200 mb-6 overflow-x-auto pb-1">
```

**优化后**：
```tsx
{/* Tab 切换：下划线式，激活态下划线使用时间银行模块紫 */}
{/* overflow-x-auto + whitespace-nowrap：移动端窄屏 Tab 文字不换行、可横向滚动，避免下划线动效错位 */}
{/* mb-5 与 SharedKitchen/SkillExchange 列表页 Tab 容器边距保持一致 */}
<div className="flex items-center gap-6 border-b border-neutral-200 mb-5 overflow-x-auto pb-1">
```

**对比说明**：三个列表页（TimeBank / SharedKitchen / SkillExchange）共享相同的页面结构（标题 + 发布按钮 → Tab → 筛选/入口 → 列表），是用户在不同模块间切换时感知最强的页面类型。TimeBank 的 Tab 容器使用 `mb-6`（24px），而 SharedKitchen 和 SkillExchange 均使用 `mb-5`（20px），同结构页面 4px 的节奏差异在快速切换模块时能被感知。统一为 `mb-5` 后，三个列表页的「Tab → 下方筛选/入口区」间距完全一致，跨模块切换时视觉节奏连贯。选择 `mb-5` 而非 `mb-6` 是因为 2/3 页面已使用 `mb-5`，且 Tab 与下方筛选区之间是「主操作 → 次级筛选」的从属关系，较紧的间距更贴合信息层级。

### 2. Layout 移动端底部导航 —— 激活态顶部线指示器

**文件**：`src/components/Layout/index.tsx`

**改动**：
为 `MobileTabItem` 激活态补充顶部线指示器（`w-6 h-0.5 rounded-full bg-neutral-900`），定位在 Tab 项上方 6px 处（`-top-1.5`）。与桌面端 `DesktopNavLink` 的底部 underline 指示器形成「移动顶部 / 桌面底部」的视觉呼应，补全移动端导航的激活态视觉锚点。

**优化前**：
```tsx
// 移动端底部 Tab 导航项
function MobileTabItem({ path, label, icon: Icon }: { path: string; label: string; icon: LucideIcon }) {
  const isActive = useIsActive(path);
  return (
    <Link
      to={path}
      aria-label={label}
      className={`flex flex-col items-center gap-0.5 text-[11px] transition-colors duration-200 ${
        isActive ? "text-neutral-900" : "text-neutral-400"
      }`}
    >
      <Icon className={`w-5 h-5 transition-transform duration-200 ${isActive ? "scale-110" : ""}`} />
      <span>{label}</span>
    </Link>
  );
}
```

**优化后**：
```tsx
// 移动端底部 Tab 导航项
function MobileTabItem({ path, label, icon: Icon }: { path: string; label: string; icon: LucideIcon }) {
  const isActive = useIsActive(path);
  return (
    <Link
      to={path}
      aria-label={label}
      className={`relative flex flex-col items-center gap-0.5 text-[11px] transition-colors duration-200 ${
        isActive ? "text-neutral-900" : "text-neutral-400"
      }`}
    >
      {/* 激活态顶部线指示器：与桌面端 DesktopNavLink 的底部 underline 形成移动/桌面视觉呼应 */}
      {isActive && (
        <span
          className="absolute -top-1.5 left-1/2 -translate-x-1/2 w-6 h-0.5 rounded-full bg-neutral-900"
          aria-hidden
        />
      )}
      <Icon className={`w-5 h-5 transition-transform duration-200 ${isActive ? "scale-110" : ""}`} />
      <span>{label}</span>
    </Link>
  );
}
```

**对比说明**：

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 激活态视觉信号 | 颜色变化（`text-neutral-900`）+ 图标缩放（`scale-110`） | 颜色变化 + 图标缩放 + **顶部线指示器** |
| 与桌面端一致性 | 桌面端有 underline，移动端无线状指示器，激活态语言不对等 | 移动端顶部线 / 桌面端底部线，形成「顶部 / 底部」对称的线状指示器语言 |
| 一眼可读性 | 仅靠颜色 + 缩放区分激活态，弱光环境或色觉不敏感用户辨识困难 | 线状指示器提供额外的形状锚点，提升一眼可读性 |

**设计决策说明**：
- **位置选择「顶部」而非「底部」**：移动端底部导航的 `border-t` 已在导航顶部形成视觉边界，顶部线指示器紧贴该边界下方，视觉上「挂」在导航顶部边缘，与桌面端 underline 紧贴导航底部边缘形成对称呼应。若放在底部，会与图标 + 文字的视觉重心争夺空间。
- **尺寸选择 `w-6 h-0.5`（24px × 2px）**：宽度 24px 约为图标（20px）的 1.2 倍，视觉上恰好覆盖图标范围；高度 2px 比桌面端 underline 的 1px（`h-px`）略厚，因为移动端屏幕更小、视距更近，需要更明显的指示器。
- **颜色选择 `bg-neutral-900`**：与激活态文字色（`text-neutral-900`）一致，避免引入新颜色破坏现有的极简灰阶配色。
- **定位 `-top-1.5`（-6px）**：Link 在 `h-16`（64px）导航内垂直居中，上下各约 14px 空间。`-top-1.5` 将指示器放置在 Link 上方 6px 处，即距导航顶部约 8px，位于 `border-t` 下方清晰可见区域。
- **`aria-hidden`**：指示器仅为视觉装饰，屏幕阅读器应忽略；激活态语义已通过 `aria-label` 与文字颜色传递。
